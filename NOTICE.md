# Provenance and attribution notice

## Recovered release

This repository's `manifest.json` and `theme.css` were recovered from an existing Obsidian installation on August 10, 2026. The recovered manifest identifies the theme as **Night Owl 1.0.0**, names **Max Qian** as its author, and links `https://github.com/AstroAir`.

The 1.0.0 preservation release is byte-identical to that installed copy:

- `manifest.json`: `0cac7a349633006aa250493899ec5c04eed2875bd2ef7cded7b692eee288e4c4`
- `theme.css`: `2f503a22fdc0f8abf88e5200135b928128152c7e071c924d69f892b5568a4ba9`

Version 1.0.3 keeps that recovered `theme.css` and only changes `manifest.json` so the Community directory listing name is **Night Owl Classic**. Directory names cannot include the word "Theme". The 1.0.3 manifest hash is `fb1adb858ffbed415bb84206b0b53c615ab23f2699cc9ee475c449c2743690f3`.

Version 1.0.4 names Mark Spirek as the current maintainer in `manifest.json` and retains the same recovered `theme.css`. Original authorship and license notices remain as documented below.

Recovery from an installed copy proves what Obsidian distributed to this installation; it does not by itself prove the complete history of the deleted source repository.

## Registry history

- The earlier Obsidian Night Owl project was published by Ben Hong at <https://github.com/bencodezen/obsidian-night-owl-theme>.
- Obsidian's official registry re-added Night Owl under Max Qian and `AstroAir/obsidian-night-owl` in commit <https://github.com/obsidianmd/obsidian-releases/commit/1db214b403e45929754f63b52a41ef9e5c333c92>.
- The later upstream URL was <https://github.com/AstroAir/obsidian-night-owl>. Both that repository and the AstroAir account are currently unavailable.
- Obsidian's official registry removed the entry in commit <https://github.com/obsidianmd/obsidian-releases/commit/b80a2193798619da5531a21885e071ff3ffb0c0d>.
- Independent registry history is available at <https://www.moritzjung.dev/obsidian-stats/themes/night-owl/>.

No maintainer statement explaining the discontinuation has been found. The unavailable upstream is consistent with an automated removal, but that is an inference rather than a confirmed reason.

## License evidence and limitation

The deleted AstroAir repository was publicly identified by GitHub as MIT-licensed, and a cached repository file listing included a `LICENSE` file. The installed Obsidian bundle contained only `manifest.json` and `theme.css`; no archived copy of the deleted repository's exact copyright line was recovered.

This repository therefore includes the standard MIT terms with the known-holder line `Copyright (c) Max Qian and contributors`, while documenting that this line is not claimed to be a verbatim recovery of the deleted file. All known author and project-lineage credits are retained here and in the README.

A previous preservation repository, https://github.com/mspirek/obsidian-night-owl, carried a public original-maintainer contact notice from 2026-08-10 through the named earliest directory date of 2026-09-09. No response was received. That repository is retired. The notice text is in [docs/PREVIOUS_REPO_CONTACT.md](docs/PREVIOUS_REPO_CONTACT.md).

If a rights holder has the original license notice, requests a correction, objects to redistribution, or wants to reclaim or transfer maintenance, please open a public issue on this repository. If stronger evidence contradicts the recorded license or attribution, redistribution will pause while the repository is corrected.

This record is intended to make the preservation history transparent; it is not legal advice.
