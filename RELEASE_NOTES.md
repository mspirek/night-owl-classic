# Night Owl Classic 1.0.3 — directory listing name

This release keeps the recovered Night Owl CSS unchanged and only updates
`manifest.json` so the theme can be submitted as **Night Owl Classic**.
The archived original listing still occupies identifier `night-owl`, and
directory names cannot include the word "Theme".
