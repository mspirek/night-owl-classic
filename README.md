# Night Owl Classic

A dark theme for Obsidian, maintained by [Mark Spirek](https://github.com/mspirek).

![Night Owl Classic preview](screenshot.png)

## Install

In Obsidian, open **Settings → Appearance → Themes → Manage**, search for **Night Owl Classic**, and select **Install and use**.

For manual installation, download `manifest.json` and `theme.css` from the [latest release](https://github.com/mspirek/night-owl-classic/releases/latest), place them in `.obsidian/themes/Night Owl Classic/`, and select the theme in Obsidian's Appearance settings.
