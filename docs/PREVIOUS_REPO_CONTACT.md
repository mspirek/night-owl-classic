# Previous-repository original-maintainer contact

The previous preservation repository was https://github.com/mspirek/obsidian-night-owl.

On **2026-08-10** that repository opened public issue #1, *Seeking the original Night Owl maintainer / intent to maintain*. The issue invited Max Qian / AstroAir and any other Night Owl rights holder or former maintainer to comment if they wanted to:

- reclaim or transfer the project
- request removal or another change to the preservation copy
- approve continued community maintenance
- provide the deleted repository's exact license notice
- correct any provenance or attribution detail

The issue said it would remain open for at least 30 days, and that **September 9, 2026** was the earliest date on which an Obsidian Community directory request would be considered.

No response was received. That previous repository is retired. Rights holders can open an issue on this repository instead.
